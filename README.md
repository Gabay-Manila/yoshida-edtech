# Yoshida EdTech Works ポータル利用手順書

本ポータル（https://yoshida-edtech.vercel.app/）は、外国人介護職員および日本語学習者が、登録不要・完全無料で自習を進められる統合Web学習環境です。

---

## 1. 基本的な使い方

1. **アクセスする**
   * スマートフォンまたはPCのブラウザから上記URLを開きます。
   * アプリのインストールやログインは不要です。

2. **アプリを探す**
   * **カテゴリタブ**: 「すべて」「試験対策」「現場実務」「語学・学習」「暮らし・案内」から絞り込めます。
   * **検索バー**: アプリ名や関連キーワードを入力して検索できます。
   * **言語レベルバッジ**: JLPT（N5〜N3）やCEFR（A2）のバッジを目安に、自分のレベルに合った教材を選べます。

3. **教材を開く**
   * 各アプリカードの「アプリを開く」をタップすると、別タブでドリルや模擬試験が直接開きます。

---

## 2. 学習ルートと進捗チェック機能の使い方

ホーム画面上部には、学習目標に合わせた4つのルート（全16ステップ）を用意しています。

* **Route 01（特定技能 介護 合格ルート）**: 渡日前〜初期の文法・語彙・CBT模試
* **Route 02（介護現場・即戦力ルート）**: 現場の声かけ・記録入力・会話発信
* **Route 03（国家試験パート合格ルート）**: 用語理解・制度足切り対策・過去問演習
* **Route 04（日常会話・相互理解ルート）**: 現代タガログ語・英語・生活献立

### 進捗チェックの手順
1. 各ステップの左側にある「丸いチェックボタン」をタップします。
2. 完了音が鳴り、緑のチェックマーク（✓）に変化し、ステップ名がグレーアウト表示になります。
3. もう一度タップすると解除されます。
4. **自動保存**: チェック状態はお使いのブラウザ（LocalStorage）に自動保存されます。ブラウザを閉じても次回アクセス時に復元されます。
   * ※端末やブラウザを変更すると進捗は引き継がれません。

## 3. 音声設定の切り替え

* 画面右上の「437Hz 音声」ボタンで、操作音・正解音のON/OFFを切り替えることができます。
* 外部の重い音声ファイルを読み込まないため、電波が不安定な環境でも快適に動作します。
